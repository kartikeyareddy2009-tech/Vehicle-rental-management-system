Vehicle Rental Management System

Project Description

The Vehicle Rental Management System is a web-based application developed using HTML, CSS and JavaScript.

It helps users view available vehicles, book vehicles, manage rental periods and track vehicle returns.

Technologies Used

- HTML
- CSS
- JavaScript

Features

- View available vehicles
- Book a vehicle
- Manage rental periods
- Track vehicle availability
- Manage vehicle returns

How to Run

Open the "index.html" file in your web browser.
